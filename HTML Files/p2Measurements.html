Measurements (II)

Here, we learn more on measurements, this time let's add more to it!

Here, we are going to introduce some measuring tools for the correct problem.

Let's introduce the soft tape or a better term, tape measure.

This is mainly used to measure height of a person!


But what if we want to measure something larger like a soccer field?

We will use the measuring wheel since it has no need for tape usage.


For anything simply around the 15 to 1m range, we use a ruler of the right length

Anything longer, we will use something like soft tape for between 1m to 10m.

If you want to measure a very large area like a park, use the measuring wheel!
