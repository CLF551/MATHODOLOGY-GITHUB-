Addition

Here we will learn more on addition!

As you can see from the example, this is adding up the number, but there is some parts to point out about carrying over a number.

So you can see 6 + 7 = 13, then we carry over the 1 to make the 4 + 3 + 1 = 8, we get 83!

Sometimes, you have to add up to three numbers, we can use this problem as an example!

248 + 43 + 2 = ???. Not a problem since you can rearrange them to make the problem easier!

We add up 248 + 2 to get 250, then add 43 to it to get 293!
